# Olivia Ezekwe - Modern 3D Storytelling Portfolio Website

A luxury, modern, 3D animated multi-page portfolio website for **Olivia Ezekwe** (Communications Strategist, Digital Communications Specialist, Brand & Content Manager, Legal Scholar).

Built with **Next.js 14 (App Router), React, Tailwind CSS, TypeScript, Three.js 3D WebGL animations, Framer Motion, and Lucide React Icons** inside the `src/` directory.

---

## 🌟 Pages Structure & Storytelling Arc (In Layout Order)

1. **Homepage (`/`)** — *Act I: The First Impression & Overview*
   - Interactive Three.js 3D WebGL particle wave & glowing cybernetic space
   - Hero banner with strategic positioning and dual CTAs: **View My Work** & **Download CV**
   - Quick About snippet with photo
   - 10-pillar **What I Do** interactive 3D cards
   - **Selected Work** project highlights with quantifiable impact metrics & interactive modal
   - **Featured Writing**, **Photography Preview**, and **Videography Preview** teasers
   - **"LET'S WORK TOGETHER"** signature CTA banner

2. **About (`/about`)** — *Act II: The Architect & Journey*
   - Full narrative bio combining communications mastery and legal intellect (LL.M, B.L, LL.B)
   - 12 **Areas of Expertise**
   - **Professional Background** timeline (SSDO, Moneywise Doctor UK, Communications Consultant, DIGC Garki)
   - **Education & Credentials** (LL.M, B.L, LL.B)
   - **Tools & Platforms** tech stack
   - **Organisations & Brands** client portfolio
   - **Outside the Brief** creative passions & mentorship

3. **Portfolio (`/portfolio`)** — *Act III: Selected Work*
   - Category filtering: *All, Communications, Digital, Branding, Photography, Videography, Reports*
   - Showcase projects: Sister Guardian Initiative, Local Government Accountability Index, My PHC Campaign, Moneywise Doctor, Sunches Villa Hotel, Dunamis Garki Media
   - Quantifiable metrics & deep-dive interactive modal
   - **What Clients Say** testimonials carousel

4. **Writing (`/writing`)** — *Act IV: The Written Word*
   - Category tabs: *Articles & Blogs, Reports & Publications, Success Stories, Press Releases & News, Newsletters*
   - Key findings, highlights, and interactive reader drawer

5. **Photography (`/photography`)** — *Act V: Through The Lens*
   - High-resolution documentary photojournalism gallery
   - Category filters: *Community & Development, Events & Conferences, Training & Workshops, Advocacy & Campaigns, Portraits, Documentary Photography*
   - Fullscreen interactive lightbox with navigation and zoom

6. **Videography (`/videography`)** — *Act VI: Motion & Emotion*
   - Categorized video showcase: *Documentaries, Interviews, Campaign Videos, Event Highlights, Reels / Short-form Videos*
   - Custom embedded video player modal

7. **Services (`/services`)** — *Act VII: Capabilities & Solutions*
   - Detailed consulting offerings: *Strategic Communications, Digital Communications, Brand Management, Multimedia Production, Reports & Publications, Capacity Building*
   - 4-Stage collaboration methodology & inquiry triggers

8. **CV / Resume (`/cv`)** — *Act VIII: Track Record & Credentials*
   - Complete executive CV with Legal background, experience timeline, skills matrix & toolsets
   - One-click **Print / Save as PDF** support

9. **Contact (`/contact`)** — *Act IX: The Next Chapter*
   - Direct contact channels: Email (`hello@oliviaezekwe.com`), LinkedIn (`linkedin.com/in/oliviaezekwe`), WhatsApp/Phone (`+234 000 000 0000`)
   - Interactive project inquiry form with service selection & feedback state

## 🚀 Getting Started

### 1. Install Dependencies (Already installed)
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Production Build & Start
```bash
npm run build
npm run start
```
